Se detectan las tablas que están dibujadas, con sus líneas. Las que se alinean sólo con espacios no se pueden distinguir del texto corriente, y adivinarlas significaría entregar de vez en cuando una tabla inventada: con una hoja de cálculo eso no se nota hasta que ya has trabajado sobre ella. Los importes salen como números para que se puedan sumar. Lo que puede ser otra cosa —un código postal, un año, una referencia— se queda como texto a propósito.
